# AI教辅智学平台 — 青岛理工大学首届AI应用创新开发大赛

> 赛道：**教学赋能类** | 作品方向：智能教辅双端平台

---

## 一、项目定位

面向高校课程教学的 **双端AI智能教辅平台**，覆盖学生"学-练-测-问"和教师"备-教-批-管"全流程：

| 端 | 核心能力 |
|---|---|
| **学生端** | 知识库检索·AI逐题讲解·智能组卷自测·多轮答疑·错题本 |
| **教师端** | 知识库管理·智能组卷·AI授课计划·AI生成PPT·学情看板 |

---

## 二、核心功能总览（经整理优化）

### 学生端

| 模块 | 说明 | 优先级 |
|---|---|---|
| 课程知识库 | 按课程→单元→知识点三级结构，支持模糊/精确检索 | P0 |
| 课程单元选择 | 学生按实际教学进度勾选要学习的单元（对接教师授课计划） | P0 |
| AI智能讲解 | 选中知识点后 AI 展开讲解，支持"讲细一点""举个例子"等多轮追问 | P0 |
| AI生成测试题 | 根据已选单元+知识掌握情况，AI生成个性化测试卷 | P0 |
| 自动判卷与解析 | 提交后AI判卷，每题给出解析+知识点溯源 | P0 |
| 错题本 | 自动归集错题，按知识点聚类，支持重做 | P1 |
| 学习报告 | 按周/月生成学习报告，可视化薄弱环节 | P1 |
| 问答助手 | 自由对话式答疑，结合知识库上下文 | P1 |

### 教师端

| 模块 | 说明 | 优先级 |
|---|---|---|
| 知识库管理 | 上传课件/教材/文档，管理课程-单元-知识点结构 | P0 |
| 题库管理 | 手动录题 + AI批量生成题目，支持编辑/审核 | P0 |
| 智能组卷 | 按知识点分布、难度、题型自动生成试卷 | P0 |
| AI制定授课计划 | 输入总学时+教学目标，AI生成按周授课计划 | P0 |
| AI辅助生成PPT | 输入章节/知识点，AI生成讲义大纲+PPT内容 | P0 |
| 学情分析看板 | 查看班级各单元掌握度、错题分布热力图 | P1 |
| 作业批改辅助 | 主观题AI预判分+教师复核 | P2 |

### 双端共用

| 能力 | 说明 |
|---|---|
| 多课程支持 | 教师可为不同课程创建独立的知识库空间 |
| 数据互通 | 学生测试结果实时反馈给教师学情看板 |
| 多模型接入 | 支持MaxKB兼容的多种大模型切换 |
| 多端部署 | Web端 + 可嵌入微信企业号 |

## 三、对原始想法的取舍说明

| 你的想法 | 处理 | 理由 |
|---|---|---|
| 学生端知识库 | ✅ 保留 | 核心 |
| 学生端题库 | ✅ 保留 | 核心 |
| AI讲解 | ✅ 保留并增强为多轮追问 | 多轮交互是比赛加分项 |
| AI生成测试题 | ✅ 保留，增强为个性化 | 相比固定题库更有创新性 |
| 按单元勾选学习 | ✅ 保留，与教师授课计划联动 | 体现双端协同 |
| 教师端知识库 | ✅ 保留 | 核心 |
| 教师端题库 | ✅ 保留 | 核心 |
| AI生成测试题（教师） | ✅ 保留，增强为智能组卷 | 组卷比单纯生成题目更有实用价值 |
| AI制定授课计划 | ✅ 保留 | 差异化亮点 |
| AI辅助生成PPT | ✅ 保留 | 亮点功能 |
| —（新增）错题本 | ➕ 新增 | 学生学习刚需 |
| —（新增）学情看板 | ➕ 新增 | 教师端闭环，数据驱动教学 |
| —（新增）判卷解析 | ➕ 新增 | 让测试形成闭环 |

## 四、推荐开发工具

根据比赛提供的平台，建议：

| 方案 | 工具 | 优势 |
|---|---|---|
| **方案A（推荐）** | 飞致云MaxKB | 已培训，RAG知识库+工作流编排成熟，适合智能体搭建 |
| 方案B | MaxKB + Python API | MaxKB做知识库和对话，Python处理组卷算法和PPT生成 |
| 方案C | 扣子(Coze) + FastGPT | 如果你更熟悉字节系工具 |
