# MaxKB智能体工作流设计

## 一、核心智能体清单

| 智能体 | 用途 | 工作流复杂度 |
|---|---|---|
| 知识库检索Agent | 语义检索+原文召回 | 低 |
| AI课程讲解Agent | 知识点讲解+多轮追问 | 中 |
| 智能组卷Agent | 按参数生成/筛选题目 | 中 |
| 自动判卷Agent | 客观题判分+主观题评估 | 中 |
| 授课计划Agent | 按学时生成计划 | 中 |
| PPT生成Agent | 大纲→内容→PPT文件 | 高 |
| 学习分析Agent | 薄弱点分析+学习建议 | 低 |

## 二、关键工作流详细设计

### 2.1 AI课程讲解 + 多轮追问

参考培训中提到的"历史聊天记录变量"机制：

```
[开始节点]
  ↓
[意图识别] ← 判断：首次提问 / 追问 / 切换话题
  ↓
[分支判断]
  ├─ 首次提问 → 知识库检索(RAG) → LLM生成讲解 → [输出]
  ├─ 追问      → 拼接历史上下文 + 检索补充 → LLM生成回答 → [输出]
  └─ 切换话题  → 清空上下文 + 重新检索 → [输出]
  ↓
[保存对话记录] → 写入历史聊天记录变量
```

### 2.2 智能组卷工作流

参考培训中"学生知识点自测"工作流的改进版：

```
[开始] 接收参数：知识点列表、题型、数量、难度
  ↓
[知识库检索] 检索各知识点对应文档片段
  ↓
[题库检索] 在已有题库中匹配题目
  ↓
[变量赋值] 统计已匹配题目数量
  ↓
[判断器] 已匹配题数 >= 需求题数？
  ├─ Yes → [组装试卷]
  └─ No  → [AI生成题目]
             ↓
           调用LLM根据知识点+文档片段生成题目
             ↓
           [题目格式校验] → 不符合则重试
             ↓
           [存入题库]（积累题库）
             ↓
           [组装试卷]
  ↓
[输出] 返回结构化试卷数据
```

### 2.3 自动判卷 + 解析工作流

```
[开始] 接收学生答案+标准答案
  ↓
[分支判断] 题型？
  ├─ 客观题(单选/多选/判断) → [直接比对] → 判分
  └─ 主观题(填空/简答)     → [LLM语义评估]
                                ↓
                               输入：标准答案+学生答案
                               ↓
                               LLM给出：得分(0-满分)+评语
  ↓
[判断器] 是否答错？
  ├─ 错 → [LLM生成解析] → 关联知识点 → 归入错题本
  └─ 对 → 跳过
  ↓
[汇总输出] 总分+逐题结果+解析+建议
```

### 2.4 AI授课计划生成

```
[开始] 接收：课程名、总学时、起止日期、周课时、教学目标
  ↓
[知识库检索] 检索教材目录+章节内容，获取章节数和内容量
  ↓
[LLM计算分配]
  输入：章节数 × 内容量 + 总学时 + 教学目标
  逻辑：按内容权重分配学时 → 按周排布 → 标注重难点
  ↓
[格式校验] 检查总学时是否匹配、周次是否合理
  ↓
[输出] 结构化的周授课计划
```

### 2.5 PPT生成工作流

```
[开始] 接收章节/知识点主题
  ↓
[知识库检索] 检索相关文档内容
  ↓
[LLM生成大纲] 输出PPT大纲（slide标题+要点）
  ↓
[用户交互节点] 确认/修改大纲（MaxKB支持表单交互）
  ↓
[循环节点] 对每个slide：
  ├─ LLM生成标题+正文要点
  ├─ [可选] 调用T2I工具生成配图
  └─ 组装slide数据
  ↓
[脚本节点] Python脚本生成.pptx文件
  ↓
[输出] 提供下载链接
```

## 三、提示词设计原则

### 3.1 知识库检索提示词模板

```
你是一个{课程名}的AI助教。请基于以下知识库内容回答学生问题。

知识库内容：
{检索结果}

学生问题：{问题}

要求：
1. 优先使用知识库中的内容，不要编造
2. 如果知识库无法回答，明确告知并建议查阅教材
3. 用学生能理解的语言讲解，适当举例
4. 回答控制在300字以内（可追问展开）
```

### 3.2 出题提示词模板

```
你是一位{课程名}的出题专家。请根据以下知识点生成题目。

知识点：{知识点名称}
参考内容：{知识库片段}
题型：{题型}
难度：{难度}
数量：{数量}

要求：
1. 题目表述清晰，无歧义
2. 考查核心概念/计算能力/理解深度
3. 提供标准答案和详细解析
4. 输出JSON格式：[{"type":"single","question":"...","options":["A...","B..."],"answer":"A","analysis":"..."}]
```

### 3.3 PPT大纲提示词模板

```
你是一位{课程名}的资深教师。请为以下章节设计PPT大纲。

章节：{章节名}
内容概要：{知识库检索内容}
风格：{风格要求}
预计页数：{页数}

要求：
1. 每页一个主题，逻辑递进
2. 包含：目标引入→概念讲解→例题→练习→小结
3. 标注每页的标题和3-5个要点
4. 可标注"此处可配图"的建议位置
```
