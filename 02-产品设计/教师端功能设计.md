# 教师端功能设计

## 一、页面结构

```
教师端
├── 首页（我的课程列表）
├── 课程管理
│   ├── 知识库管理（上传/编辑/审核）
│   ├── 题库管理（录题/生成/审核）
│   ├── 智能组卷
│   ├── 授课计划
│   ├── PPT生成
│   ├── 学情看板
│   └── 作业管理
└── 个人中心
```

## 三、关键智能体工作流

### 3.1 智能组卷工作流

```
输入参数(知识点、难度、题型、数量)
  → 知识库检索匹配相关知识点
  → 题库召回候选题目
  → LLM判断：题库够用？→ Yes：直接组卷
                     → No：AI生成补足题目
  → 题目难度校验
  → 自动排版配分
  → 输出试卷
```

### 3.2 PPT生成工作流

```
输入(章节主题)
  → 知识库检索章节内容
  → LLM生成大纲 → 用户确认/修改
  → 逐页生成内容(标题+要点+说明)
  → 可调用T2I生成配图(可选)
  → 组装为pptx文件
  → 输出下载
```
