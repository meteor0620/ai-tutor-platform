# 学生端功能设计

## 一、页面结构

```
学生端
├── 首页（课程列表）
├── 课程详情
│   ├── 学习看板（进度、授课计划）
│   ├── 知识库（浏览/检索/讲解）
│   ├── 自测中心（生成试卷/作答/查看结果）
│   ├── 错题本
│   ├── 学习报告
│   └── AI助手（自由问答）
└── 个人中心
```

## 二、核心页面设计

### 2.1 课程首页

- 顶部：课程名称、教师信息
- 中部：学习进度环状图（已掌握X/总知识点Y）
- 下方：教师最新授课计划（本周安排）
- 入口卡片：知识库、自测、错题本、AI助手

│   ├── 1.2 xxx [📖 学习中]

## 三、关键交互细节

### 3.1 多轮追问（亮点）

- 保持对话上下文，学生可追问"为什么""举个例子""总结一下"
- 引用具体知识点时，自动定位到知识库对应段落
- 结合MaxKB的长记忆功能，记录学生历史提问

### 3.2 智能讲解模式

针对不同学生水平，AI讲解自动调节：
- **初级**：比喻+生活化例子
- **中级**：结合教材原文+适度扩展
- **高级**：跨章节关联+学术前沿补充

### 3.3 沉浸式答题体验

- 支持逐题作答和整卷作答两种模式
- 倒计时功能（可选）
- 作答中途退出自动保存进度
