# 功能需求清单

## 一、学生端功能

### 1.1 课程空间（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-01 | 加入课程 | 学生通过课程码/链接加入教师创建的课程 |
| S-02 | 课程首页 | 展示课程信息、学习进度、教师最新通知 |
| S-03 | 单元选择 | 按教师授课计划展示单元列表，学生可勾选已完成/待学习单元 |

### 1.2 知识库与学习（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-04 | 知识库浏览 | 按课程→单元→知识点三级结构浏览 |
| S-05 | 知识库检索 | 输入关键词搜索知识点，支持语义搜索 |
| S-06 | AI智能讲解 | 选择知识点后AI展开讲解，支持多轮追问（讲细/举例/总结） |
| S-07 | 学习打卡 | 标记知识点为"已掌握/需复习"，驱动测试题生成 |

### 1.3 测试与自测（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-08 | AI生成测试题 | 根据已选单元+薄弱知识点，AI动态生成个性化试卷 |
| S-09 | 自定义组卷 | 学生自选题型、数量、难度 |
| S-10 | 在线作答 | 支持单选/多选/判断/填空/简答 |
| S-11 | 自动判卷 | 客观题自动判分，简答题AI预判分 |
| S-12 | 逐题解析 | 每题展示正确答案+解析+关联知识点 |

### 1.4 错题本（P1）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-13 | 错题归集 | 自动收录错题，按知识点聚类 |
| S-14 | 错题重做 | 选择错题重新作答，支持反复练习 |
| S-15 | 错题导出 | 导出为PDF/Word |

### 1.5 学习报告（P1）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-16 | 周报/月报 | 自动生成学习时长、完成题目数、正确率趋势 |
| S-17 | 薄弱点分析 | 雷达图展示各知识点掌握度 |
| S-18 | 学习建议 | AI根据薄弱点推荐下一步学习内容 |

### 1.6 问答助手（P1）
| 编号 | 功能 | 描述 |
|---|---|---|
| S-19 | 自由问答 | 对话式提问，基于课程知识库回答 |
| S-20 | 学习建议咨询 | 询问"这个章节怎么学""重点是什么"等 |

## 二、教师端功能

### 2.1 课程与知识库管理（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-01 | 创建课程 | 填写课程名称、简介、封面 |
| T-02 | 知识库管理 | 上传课件PDF/PPT/Word/教材，自动分段入库 |
| T-03 | 知识点编辑 | 手动增删改知识点，调整课程-单元-知识点结构 |
| T-04 | 知识库审核 | 预览AI分段结果，修正错误分割 |

### 2.2 题库管理（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-05 | 手动录题 | 逐题录入，支持单选/多选/判断/填空/简答 |
| T-06 | AI批量生成 | 选择知识点+题型+数量，AI批量生成并存入题库 |
| T-07 | 题目审核 | 预览/编辑/删除AI生成的题目 |
| T-08 | 题库导入导出 | 支持Excel批量导入导出 |

### 2.3 智能组卷（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-09 | 智能组卷 | 设置知识点分布、难度比例、题型数量，自动生成试卷 |
| T-10 | 手动组卷 | 从题库手动挑选题目组成试卷 |
| T-11 | 试卷管理 | 保存、编辑、发布试卷给学生 |

### 2.4 授课计划（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-12 | 输入参数 | 填写课程名称、总学时、教学目标、起止日期 |
| T-13 | AI生成计划 | 按周生成授课主题、教学内容、重点难点、作业安排 |
| T-14 | 计划编辑 | 拖拽调整，手动修改计划内容 |
| T-15 | 计划发布 | 发布后学生端自动同步单元学习安排 |

### 2.5 AI生成PPT（P0）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-16 | 输入主题 | 输入章节、知识点、风格偏好 |
| T-17 | 生成大纲 | AI先生成PPT大纲供教师确认 |
| T-18 | 生成PPT | 确认大纲后生成完整PPT（含文字+配图建议） |
| T-19 | 下载导出 | 导出为.pptx或PDF |

### 2.6 学情分析（P1）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-20 | 班级总览 | 整体正确率、完成率、活跃度 |
| T-21 | 知识点热力图 | 各知识点班级掌握度分布 |
| T-22 | 学生个体分析 | 查看单个学生薄弱点、学习曲线 |
| T-23 | 错题统计 | 高频错题排行，指导教学重点调整 |

### 2.7 作业管理（P2）
| 编号 | 功能 | 描述 |
|---|---|---|
| T-24 | 发布作业 | 选择试卷/题目发布为作业，设置截止时间 |
| T-25 | 批改辅助 | 简答题AI预判分+评语，教师确认或修正 |
| T-26 | 成绩导出 | 导出成绩单为Excel |

---

## 三、通用功能

| 编号 | 功能 | 描述 |
|---|---|---|
| G-01 | 用户注册登录 | 对接学校统一认证或微信企业号 |
| G-02 | 角色切换 | 支持教师/学生身份切换（如研究生兼助教场景） |
| G-03 | 消息通知 | 新作业、新测试、授课计划更新等通知 |
| G-04 | 数据导出 | 支持学习数据、成绩数据导出 |

---

## 四、优先级说明

| 优先级 | 含义 |
|---|---|
| P0 | 必须实现，比赛作品核心功能 |
| P1 | 重要功能，时间充裕则实现 |
| P2 | 锦上添花，完成P0/P1后再做 |
