# 系统架构设计

## 一、应用划分（MaxKB多应用架构）

在MaxKB中创建以下独立应用，每个应用对应一个功能模块：

| 应用ID | 应用名称 | 用途 | 访问权限 |
|---|---|---|---|
| app-kb | 知识库服务 | 文档上传、分段、检索 | 教师管理/学生只读 |
| app-stu | 学生端主应用 | 学习、讲解、自测、问答 | 学生 |
| app-tch | 教师端主应用 | 知识库管理、组卷、计划、PPT | 教师 |
| app-exam | 智能组卷服务 | 题目生成、组卷逻辑 | 内部调用 |
| app-grade | 判卷服务 | 自动判分、解析生成 | 内部调用 |

## 二、知识库结构设计

### 2.1 知识库分层

```
课程知识库（每个课程一个知识库）
├── 元数据层（标签/分类）
│   ├── 课程名称
│   ├── 单元编号
│   ├── 知识点ID
│   └── 内容类型（定义/定理/例题/习题）
│
├── 文档层（原始分段）
│   ├── 教材片段
│   ├── 课件片段
│   └── 补充资料片段
│
└── 题库层（结构化题目）
    ├── 题目标签：知识点ID、题型、难度
    ├── 题目内容
    ├── 标准答案
    └── 解析
```

### 2.2 自定义标签体系

MaxKB知识库分段支持自定义标签，利用标签实现多维度检索：

| 标签名 | 示例值 | 用途 |
|---|---|---|
| course | 高等数学 | 课程标识 |
| unit | 第一章 | 单元 |
| topic | 函数概念 | 知识点 |
| type | definition/theorem/example | 内容类型 |
| difficulty | easy/medium/hard | 难度（题库用） |
| q_type | single/multi/judge/fill/short | 题型（题库用） |

## 三、数据流设计

### 3.1 学生自测完整数据流

```
┌── 学生端 ──┐          ┌── 内部服务 ──┐         ┌── 教师端 ──┐
│             │          │               │         │             │
│ 1.选择单元  │─────────→│ app-exam      │         │             │
│   难度参数  │          │  ·检索知识库   │         │             │
│             │          │  ·检索题库    │         │             │
│             │          │  ·LLM生成题目 │         │             │
│ 2.作答      │←─────────│  ·返回试卷    │         │             │
│             │          │               │         │             │
│ 3.提交答案  │─────────→│ app-grade     │         │             │
│             │          │  ·客观题判分   │         │             │
│             │          │  ·主观题评估   │         │             │
│ 4.查看结果  │←─────────│  ·生成解析    │         │             │
│             │          │               │         │             │
│ 5.错题归集  │          │               │─────────→│ 6.学情更新   │
└─────────────┘          └───────────────┘         └─────────────┘
```

### 3.2 知识点→题目 映射关系

```
知识点1 ←→ 题目A, 题目B, 题目C
知识点2 ←→ 题目D, 题目E
...

检索逻辑：
1. 根据学生选择的知识点列表，用标签过滤题库
2. 若题库不足，调用LLM根据知识点关联的文档片段生成新题
3. 按难度分层抽取，保证难度分布合理
```

## 四、PPT生成技术流程

由于MaxKB本身不直接生成PPT文件，采用"AI生成内容 + Python脚本拼装"的方案：

```
用户输入章节/主题
  ↓
MaxKB工作流：知识库检索 → LLM生成大纲
  ↓
用户确认大纲（可在MaxKB表单中交互）
  ↓
MaxKB工作流循环：逐页生成标题+正文
  ↓
汇总所有页面数据（JSON格式）
  ↓
MaxKB调用自定义Python工具：
  python-pptx脚本读取JSON → 生成.pptx文件
  ↓
返回文件下载链接
```

**Python脚本核心逻辑**（伪代码）：
```python
from pptx import Presentation
from pptx.util import Inches, Pt
import json

def generate_ppt(slides_data, output_path):
    prs = Presentation()
    for slide_info in slides_data:
        slide = prs.slides.add_slide(prs.slide_layouts[1])
        slide.shapes.title.text = slide_info['title']
        slide.placeholders[1].text = slide_info['content']
    prs.save(output_path)
    return output_path
```
