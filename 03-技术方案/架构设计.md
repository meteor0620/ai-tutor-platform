## 三、数据流设计(实际)

### 3.1 学生自测完整数据流(已实现,走FastAPI)

```
学生端(Vue3 :5173)
  → 选择科目/单元 → POST /api/papers (FastAPI组卷:按知识点/难度抽题,题库不足则DeepSeek生成)
  → 在线作答 → POST /api/papers/{id}/submit (FastAPI判卷:客观题比对 + 主观题LLM评估)
  → 逐题解析 + 知识点溯源 → 错题自动归入 /api/wrong-book
  → 教师学情看板:读取 /api/attempts + /api/wrong-book 聚合统计(建设中)
```

### 3.2 知识点→题目 映射关系(FastAPI SQLite)

```
知识点(标签) → 题目
检索逻辑:
1. 根据学生选择的知识点列表,过滤题库
2. 若题库不足,调用DeepSeek根据知识点生成新题并入库
3. 按难度分层抽取,保证难度分布合理
```
