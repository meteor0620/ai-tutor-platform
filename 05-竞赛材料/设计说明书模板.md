## 二、作品简介（300字以内）

AI教辅智学平台是一款面向高校课程教学的双端智能平台，覆盖学生"学-练-测-问"和教师"备-教-批-管"全流程。学生端支持按单元选择学习内容、AI智能讲解与多轮追问、个性化自测与自动判卷、错题归集与学习报告；教师端提供知识库与题库管理、AI智能组卷、AI授课计划生成、AI辅助PPT制作及学情分析看板。平台依托飞致云MaxKB智能体搭建平台，基于RAG技术实现课程知识库的高效检索与问答，通过工作流编排实现复杂的多步骤AI任务。作品旨在减轻教师备课组卷负担，为学生提供24小时AI学习助手，推动AI与高校教学深度融合。

## 三、需求分析

### 3.1 用户痛点

**学生端**：
- 课后缺乏即时答疑渠道，难题无法及时解决
- 不了解自身薄弱点，复习缺乏针对性
- 传统刷题方式效率低，错题无系统管理

**教师端**：
- 出卷耗时长（选题、排版、配分繁琐）
- 授课计划编写重复劳动
- PPT制作占用大量备课时间
- 无法实时掌握班级整体和个体学情

### 3.2 解决方案

通过AI智能体技术构建双端教辅平台：
- 知识库RAG检索实现24小时智能答疑
- AI动态组卷+自动判卷形成"测-评-学"闭环
- AI辅助生成授课计划和PPT减轻教师负担
- 数据看板实现学情可视化

## 五、技术实现

### 5.1 技术架构

- 智能体平台：飞致云MaxKB
- RAG知识库：基于PgVector的向量化存储与混合检索
- 工作流编排：MaxKB低代码工作流引擎
- 大模型：接入学校提供的免费Token模型
- 扩展工具：Python脚本（PPT生成 python-pptx、数据处理 pandas）
- 前端：MaxKB内置应用界面

### 5.2 核心工作流

**智能组卷工作流**：
知识库检索 → 题库召回 → 判断题库充足性 → AI补足生成 → 难度校验 → 排版输出

**自动判卷工作流**：
接收答案 → 分题型处理（客观题直接比对/主观题LLM评估）→ 生成解析 → 错题归集

**PPT生成工作流**：
知识库检索 → LLM生成大纲 → 用户确认 → 逐页生成内容 → Python脚本拼装.pptx

### 5.3 关键创新点

1. **双端协同闭环**：学生测试数据实时反馈教师学情看板，形成教学闭环
2. **个性化自测**：基于学生薄弱知识点动态生成试卷，而非固定题库
3. **多轮追问讲解**：利用MaxKB长记忆+历史上下文实现深度交互学习
4. **低代码+扩展**：MaxKB编排核心AI流程 + Python脚本处理复杂文件操作

## 六、应用场景与价值

### 6.1 典型使用场景

| 场景 | 描述 |
|---|---|
| 课后自学 | 学生按授课计划选择单元，AI讲解+自测巩固 |
| 考前复习 | AI根据错题本薄弱点推荐重点复习内容+针对性组卷 |
| 教师备课 | 一键生成授课计划+PPT，节省大量备课时间 |
| 阶段测试 | 教师AI智能组卷→发布→自动判卷→查看学情 |

### 6.2 预期效果

- 学生答疑等待时间从"半天到一天"降至"实时秒回"
- 教师出卷时间从"3-4小时"降至"10-15分钟"
- 学生可根据薄弱点精准复习，避免盲目刷题
- 教师通过学情数据及时调整教学策略
