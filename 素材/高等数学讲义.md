## 第一章 函数与极限

### 1.1 函数的概念

**定义**：设 x 与 y 是两个变量，若存在一个法则 f，使得对于 x 的每一个取值，按法则 f 都有唯一确定的 y 与之对应，则称 y 是 x 的函数，记作 y = f(x)。x 称为自变量，y 称为因变量。

**定义域与值域**：使函数有意义的自变量 x 的取值集合称为定义域；对应的因变量 y 的取值集合称为值域。

**常见基本初等函数**：
- 幂函数：y = x^α
- 指数函数：y = a^x（a>0 且 a≠1）
- 对数函数：y = log_a(x)（a>0 且 a≠1）
- 三角函数：y = sin x, cos x, tan x 等
- 反三角函数：y = arcsin x, arccos x, arctan x 等

**典型例题 1**：求函数 f(x) = √(x-1) + 1/(x-2) 的定义域。
解：√(x-1) 要求 x-1≥0，即 x≥1；1/(x-2) 要求 x≠2。故定义域为 [1,2) ∪ (2,+∞)。

### 1.2 数列的极限

**定义**：设 {a_n} 是一个数列，若存在常数 A，使得当 n 无限增大时，a_n 无限趋近于 A，则称 A 为数列 {a_n} 的极限，记作 lim(n→∞) a_n = A。

**极限的性质**：
- 唯一性：数列极限若存在，则唯一
- 有界性：收敛数列必有界
- 保号性：若 lim a_n = A > 0，则存在正整数 N，当 n>N 时 a_n > 0

**典型例题 2**：求 lim(n→∞) (3n²+2n)/(2n²-5)。
解：分子分母同除以 n²，得 lim(n→∞) (3+2/n)/(2-5/n²) = (3+0)/(2-0) = 3/2。

### 1.3 函数的极限

**x→x₀ 时的极限**：若当 x 无限趋近于 x₀（但 x≠x₀）时，f(x) 无限趋近于常数 A，则称 A 为 f(x) 在 x→x₀ 时的极限，记作 lim(x→x₀) f(x) = A。

**x→∞ 时的极限**：若当 |x| 无限增大时，f(x) 无限趋近于常数 A，则称 A 为 f(x) 在 x→∞ 时的极限。

**两个重要极限**：
1. lim(x→0) sin x / x = 1
2. lim(x→∞) (1 + 1/x)^x = e

**无穷小与无穷大**：极限为零的变量称为无穷小；|f(x)| 无限增大的变量称为无穷大。

### 1.4 函数的连续性与间断点

**连续性定义**：若 lim(x→x₀) f(x) = f(x₀)，则称 f(x) 在点 x₀ 处连续。

**间断点分类**：
- 第一类间断点：左右极限都存在。若相等则为可去间断点，不等则为跳跃间断点
- 第二类间断点：左右极限至少有一个不存在（如无穷间断点、振荡间断点）

**闭区间上连续函数的性质**：
- 最值定理：闭区间上连续函数必能取到最大值和最小值
- 介值定理：闭区间上连续函数可取到介于端点函数值之间的任意值

## 第二章 导数与微分

### 2.1 导数的概念

**定义**：设函数 y = f(x) 在点 x₀ 的某邻域内有定义，若极限
lim(Δx→0) [f(x₀+Δx) - f(x₀)] / Δx
存在，则称 f(x) 在 x₀ 处可导，该极限值称为 f(x) 在 x₀ 处的导数，记作 f'(x₀)。

**导数的几何意义**：f'(x₀) 是曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

**可导与连续的关系**：若函数在某点可导，则必在该点连续；但连续不一定可导。

### 2.2 基本求导公式

- (C)' = 0
- (x^n)' = n·x^(n-1)
- (sin x)' = cos x
- (cos x)' = -sin x
- (tan x)' = sec²x
- (a^x)' = a^x·ln a
- (e^x)' = e^x
- (log_a x)' = 1/(x·ln a)
- (ln x)' = 1/x

### 2.3 求导法则

**四则运算法则**：
- (u ± v)' = u' ± v'
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv')/v²

**复合函数链式法则**：若 y = f(u)，u = g(x)，则 dy/dx = dy/du · du/dx。

**典型例题 3**：求 y = sin(2x+1) 的导数。
解：令 u = 2x+1，则 y' = cos(u) · (2x+1)' = 2cos(2x+1)。

### 2.4 微分

**定义**：若函数增量 Δy 可表示为 Δy = A·Δx + o(Δx)，其中 A 与 Δx 无关，则称 f(x) 在 x₀ 处可微，A·Δx 称为微分，记作 dy = f'(x₀)·Δx = f'(x₀)dx。

**微分形式不变性**：dy = f'(u)·du，其中 u 可以是自变量也可以是中间变量。

## 第三章 中值定理与导数的应用

### 3.1 中值定理

**罗尔定理**：若 f(x) 在 [a,b] 上连续，在 (a,b) 内可导，且 f(a)=f(b)，则存在 ξ∈(a,b)，使 f'(ξ)=0。

**拉格朗日中值定理**：若 f(x) 在 [a,b] 上连续，在 (a,b) 内可导，则存在 ξ∈(a,b)，使
f'(ξ) = [f(b) - f(a)] / (b - a)

### 3.2 洛必达法则

**适用情形**：求 0/0 型或 ∞/∞ 型未定式极限时，可对分子分母分别求导再求极限：
lim f(x)/g(x) = lim f'(x)/g'(x)（在满足条件下）

**典型例题 4**：求 lim(x→0) (e^x - 1)/x。
解：0/0 型，用洛必达法则，原式 = lim(x→0) e^x/1 = 1。

### 3.3 函数单调性与极值

**单调性判别**：若在区间内 f'(x)>0，则 f(x) 单调递增；若 f'(x)<0，则 f(x) 单调递减。

**极值判别（一阶充分条件）**：若 x₀ 两侧导数符号由正变负，则 x₀ 为极大值点；由负变正则为极小值点。

**极值判别（二阶充分条件）**：若 f'(x₀)=0 且 f''(x₀)<0，则 x₀ 为极大值点；若 f''(x₀)>0，则 x₀ 为极小值点。

### 3.4 凹凸性与拐点

- 若 f''(x)>0，则曲线是凹的（向上弯曲）
- 若 f''(x)<0，则曲线是凸的（向下弯曲）
- 曲线凹凸性发生改变的点称为拐点

## 第四章 不定积分

### 4.1 不定积分的概念

**定义**：若 F'(x) = f(x)，则 F(x) 称为 f(x) 的一个原函数。f(x) 的所有原函数 F(x)+C 称为 f(x) 的不定积分，记作 ∫f(x)dx = F(x) + C，其中 C 为任意常数。

### 4.2 基本积分公式

- ∫x^n dx = x^(n+1)/(n+1) + C（n≠-1）
- ∫1/x dx = ln|x| + C
- ∫e^x dx = e^x + C
- ∫sin x dx = -cos x + C
- ∫cos x dx = sin x + C
- ∫sec²x dx = tan x + C
- ∫1/(1+x²) dx = arctan x + C
- ∫1/√(1-x²) dx = arcsin x + C

### 4.3 换元积分法

**第一类换元法（凑微分法）**：∫f[φ(x)]·φ'(x)dx = ∫f(u)du（令 u = φ(x)）。

**第二类换元法**：常用于去根号，如令 x = sin t 等。

**典型例题 5**：求 ∫2x·e^(x²) dx。
解：令 u = x²，则 du = 2x dx，原式 = ∫e^u du = e^u + C = e^(x²) + C。

### 4.4 分部积分法

**公式**：∫u dv = uv - ∫v du。

**典型例题 6**：求 ∫x·e^x dx。
解：令 u = x，dv = e^x dx，则 du = dx，v = e^x，原式 = x·e^x - ∫e^x dx = x·e^x - e^x + C。

## 第五章 定积分

### 5.1 定积分的概念

**定义**：设 f(x) 在 [a,b] 上有界，若无论对区间怎么分割、ξᵢ 怎么取，极限
lim Σ f(ξᵢ)·Δxᵢ（当最大小区间长度趋于0）
都存在且相等，则称该极限值为 f(x) 在 [a,b] 上的定积分，记作 ∫(a→b) f(x) dx。

**几何意义**：定积分表示曲线与 x 轴围成的曲边梯形的有向面积。

### 5.2 定积分的性质

- ∫(a→b) k·f(x) dx = k·∫(a→b) f(x) dx
- ∫(a→b) [f(x) ± g(x)] dx = ∫(a→b) f(x) dx ± ∫(a→b) g(x) dx
- ∫(a→b) f(x) dx = ∫(a→c) f(x) dx + ∫(c→b) f(x) dx（a<c<b）
- ∫(a→b) f(x) dx = -∫(b→a) f(x) dx
- 若 f(x) ≥ 0，则 ∫(a→b) f(x) dx ≥ 0

### 5.3 微积分基本定理（牛顿-莱布尼茨公式）

**积分上限函数**：Φ(x) = ∫(a→x) f(t) dt，则 Φ'(x) = f(x)。

**牛顿-莱布尼茨公式**：若 F(x) 是 f(x) 的一个原函数，则
∫(a→b) f(x) dx = F(b) - F(a)

**典型例题 7**：求 ∫(0→1) x² dx。
解：原函数 F(x) = x³/3，所以 ∫(0→1) x² dx = F(1) - F(0) = 1/3。

### 5.4 定积分的应用

**平面图形的面积**：两条曲线 y=f(x), y=g(x)（f≥g）与直线 x=a, x=b 围成的面积
S = ∫(a→b) [f(x) - g(x)] dx

**旋转体体积**：曲线 y=f(x) 绕 x 轴旋转一周所得旋转体体积
V = π·∫(a→b) [f(x)]² dx

## 第六章 多元函数微分学

### 6.1 多元函数的基本概念

**二元函数**：设 D 是平面上的点集，若对于每个点 (x,y)∈D，按照某一法则 f 都有唯一确定的实数 z 与之对应，则称 z 是 (x,y) 的二元函数，记作 z = f(x,y)。

### 6.2 偏导数

**定义**：固定 y，对 x 求导得到关于 x 的偏导数：
∂z/∂x = lim(Δx→0) [f(x+Δx, y) - f(x, y)] / Δx
类似地定义关于 y 的偏导数 ∂z/∂y。

### 6.3 全微分

**定义**：若函数增量 Δz 可表示为 Δz = A·Δx + B·Δy + o(ρ)（其中 ρ = √(Δx²+Δy²)），则称 z 在点 (x,y) 处可微，全微分为
dz = ∂z/∂x · dx + ∂z/∂y · dy

### 6.4 多元复合函数求导（链式法则）

若 z = f(u,v)，u = u(x,y)，v = v(x,y)，则
∂z/∂x = ∂z/∂u · ∂u/∂x + ∂z/∂v · ∂v/∂x
∂z/∂y = ∂z/∂u · ∂u/∂y + ∂z/∂v · ∂v/∂y

### 6.5 多元函数的极值

**必要条件**：若 f(x,y) 在点 (x₀,y₀) 处有极值且偏导数存在，则 f_x(x₀,y₀) = 0 且 f_y(x₀,y₀) = 0，该点称为驻点。

**充分条件**：设 (x₀,y₀) 为驻点，令 A = f_xx，B = f_xy，C = f_yy，记 Δ = AC - B²：
- 若 Δ > 0 且 A < 0，则为极大值
- 若 Δ > 0 且 A > 0，则为极小值
- 若 Δ < 0，则不是极值（鞍点）

## 第七章 二重积分

### 7.1 二重积分的概念

**定义**：设 f(x,y) 在有界闭区域 D 上有定义，对 D 作分割并取和式极限，若极限存在且与分割方式无关，则称该极限值为 f(x,y) 在 D 上的二重积分，记作 ∬(D) f(x,y) dσ。

**几何意义**：当 f(x,y) ≥ 0 时，二重积分表示以 D 为底、f(x,y) 为顶的曲顶柱体的体积。

### 7.2 直角坐标系下的计算

**先 y 后 x（X 型区域）**：D = {(x,y) | a≤x≤b, φ₁(x)≤y≤φ₂(x)}，则
∬(D) f(x,y) dσ = ∫(a→b) [∫(φ₁(x)→φ₂(x)) f(x,y) dy] dx

**先 x 后 y（Y 型区域）**：D = {(x,y) | c≤y≤d, ψ₁(y)≤x≤ψ₂(y)}，则
∬(D) f(x,y) dσ = ∫(c→d) [∫(ψ₁(y)→ψ₂(y)) f(x,y) dx] dy

### 7.3 极坐标系下的计算

**坐标变换**：x = r·cos θ，y = r·sin θ，面积元素 dσ = r·dr·dθ。
∬(D) f(x,y) dσ = ∬(D') f(r·cos θ, r·sin θ) · r · dr·dθ

## 第八章 微分方程

### 8.1 微分方程的基本概念

**微分方程**：含有未知函数及其导数的方程称为微分方程。
**阶数**：方程中未知函数最高阶导数的阶数。
**通解与特解**：含任意常数的解称为通解；由初始条件确定常数后的解称为特解。

### 8.2 可分离变量的微分方程

**形式**：dy/dx = f(x)·g(y)，可化为 dy/g(y) = f(x)dx 两边积分求解。

### 8.3 一阶线性微分方程

**形式**：y' + P(x)y = Q(x)。
**通解公式**：
y = e^(-∫P(x)dx) · [∫Q(x)·e^(∫P(x)dx) dx + C]

### 8.4 二阶常系数齐次线性微分方程

**形式**：y'' + py' + qy = 0。
**特征方程法**：写出特征方程 r² + pr + q = 0：
- 两相异实根 r₁, r₂：通解 y = C₁e^(r₁x) + C₂e^(r₂x)
- 两相等实根 r：通解 y = (C₁ + C₂x)·e^(rx)
- 共轭复根 r = α ± iβ：通解 y = e^(αx)·(C₁cos βx + C₂sin βx)

**典型例题 8**：求 y'' - 3y' + 2y = 0 的通解。
解：特征方程 r² - 3r + 2 = 0，得 r₁ = 1, r₂ = 2。通解 y = C₁e^x + C₂e^(2x)。
